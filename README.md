
# KODES – Personal Portfolio Website

A modern, responsive personal portfolio website built using HTML5, CSS3 and vanilla JavaScript.

## Project Overview

KODES is a personal portfolio website designed to showcase professional background, education, technical skills, development progress and practical projects.

## Problem Being Solved

A professional portfolio provides a central online location where an individual can introduce their professional identity, demonstrate skills and showcase practical work.

## Features

- Responsive navigation.
- Professional introduction.
- About section.
- Technical skills showcase.
- Education and experience timeline.
- Project filtering.
- Interactive contact form validation.
- Automatic footer year.
- Back-to-top functionality.
- Mobile-friendly interface.
- Accessibility considerations.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive layouts.
- JavaScript – Interactivity and validation.
- Git – Version control.
- GitHub – Online repository hosting.

## Installation and Running

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser.

No additional packages are required.

## Testing

Test the following:

- Navigation links.
- Mobile navigation.
- Project filters.
- Contact form validation.
- Invalid email handling.
- Empty form submission.

- Back-to-top button.
- Footer year.

## Known Limitations

- The contact form does not transmit messages.
- There is no database.
- There is no authentication.
- Some projects are planned rather than completed.
